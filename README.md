📌 Task Manager App

A simple and efficient full-stack web application to manage daily tasks with ease and productivity.

🚀 Features
➕ Add, update, and delete tasks
✔️ Mark tasks as completed / pending
📊 Clean and responsive UI
🔄 Real-time task updates
🔐 Secure backend API integration
🛠 Tech Stack
Frontend: React.js / HTML / CSS
Backend: Node.js / Express
Database: MongoDB
Deployment: Vercel / Render
🎯 Purpose

Helps users organize daily work, improve productivity, and track progress efficiently in a simple UI.
